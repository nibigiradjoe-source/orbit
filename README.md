# Orbit

Joe's personal learning school: a 2026–2028 roadmap (Google Project Management, CAPM, Python, AI agents, data, finance and more) turned into lessons, quizzes, exams, spaced review and 3D/animated explainers.

- Works offline after the first visit (service worker caches every course file).
- Installable on phone and laptop (Add to Home Screen / Install app).
- Progress is saved on this device; use **Settings → Export / Import** to move it between devices.
- English and French.

Open it: https://nibigiradjoe-source.github.io/orbit/
